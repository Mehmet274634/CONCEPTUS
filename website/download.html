01

GitHub deposunu klonla

macOS (Apple Silicon & Intel) üzerinde Node.js 20+ kuruluysa 30 saniyede yerel masaüstü stüdyosunu ayağa kaldırabilirsin.

zsh 
$ git clone https://github.com/Mehmet274634/CONCEPTUS.git
$ cd CONCEPTUS
02

Bağımlılıkları kur ve derle

Arayüz ve Electron masaüstü katmanını tek komutla hazırlar.

zsh 
$ npm install && npm run build
03

Masaüstü uygulamasını başlat

Yerel Electron penceresini başlatır; istersen npm start ile yalnızca tarayıcı stüdyosu olarak da çalıştırabilirsin.

zsh 
$ npm run desktop:dev
# or local browser mode:
$ npm start
