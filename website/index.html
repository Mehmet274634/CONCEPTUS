Sık Sorulanlar

Kurmadan önce bilmek istediklerin.

Kurulum, güvenlik ve desteklenen araçlarla ilgili en net cevaplar.

API anahtarı veya yeni bir ücretli abonelik gerekiyor mu? +

Hayır. CONCEPTUS tamamen ücretsiz ve MIT lisanslıdır. Bilgisayarında zaten oturum açtığın Antigravity, Claude Code, Codex veya Gemini CLI aboneliklerini doğrudan kullanır; ekstra token faturası çıkarmaz.

Bilgisayarımda sadece 1 tane AI CLI kuruluysa çalışır mı? +

Evet. Tek bir CLI (örneğin yalnızca Antigravity veya Claude Code) ile de birden fazla farklı rol ve model atayarak çoklu-ajan tartışması yapabilirsin. Birden fazla CLI kuruluysa farklı sağlayıcıları aynı masada çarpıştırır.

Windows'ta Node.js veya terminal kurmam gerekir mi? +

Hayır. Windows için tek tıkla kurulan yerel CONCEPTUS-Setup-4.2.0.exe ve kurulumsuz Portable.exe paketleri her şeyi içinde barındırır; çift tıklayıp masaüstü uygulaması olarak doğrudan açarsın.

Üretilen 5'li MD paketini Cursor, Antigravity veya Claude Code'a nasıl veririm? +

CONCEPTUS içinde 'Klasöre Kaydet' dediğinde 01..05 MD dosyaları ve otomatik AGENTS.md köprüsü seçtiğin proje klasörüne yazılır. Ardından 05_AGENTS_START_HERE.md içindeki hazır Başlangıç Promptunu tek tıkla kopyalayıp kodlama ajanına yapıştırman yeterli.

Windows SmartScreen uyarısı çıkarsa neden çıkar ve nasıl doğrularım? +

Açık kaynaklı bağımsız sürümlerde ücretli kurumsal kod imzalama sertifikası bulunmadığı için Windows ilk çalıştırmada uyarı gösterebilir. İndirme sayfasındaki PowerShell SHA-256 komutuyla dosyanın GitHub Releases özetiyle birebir eşleştiğini doğrulayıp güvenle kurabilirsin.
